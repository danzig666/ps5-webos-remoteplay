# Native client and M0 upstream sources and notices

All repository revisions are fixed in upstream.lock.json. Fetch with scripts/fetch-upstream.py.

- Aurora-TV (GuiDev1994 and Moonlight TV contributors), GPL-3.0: platform/webos/aurora_filter.inc is an unchanged extraction of str_contains_ci/webos_name_is_non_gamepad from src/app/input/input_gamepad.c. input_bridge.c adapts its startup/reconnect scan, instance-ID deduplication, gamepad shape filter, SDL rumble and diagnostics. The bundled extra mapping database is copied from deploy/webos/assets/gamecontrollerdb_extra.txt. No Moonlight transport is included. Full GPL text: LICENSE.
- SS4S (upstream authors), LGPL-3.0: exact source files are compiled unchanged. cmake/SS4SM0.cmake selects the core and NDL webOS5 backend only. Its compatibility NDL headers come from its mocks/include/libndl-media, as in the upstream build fallback. The actual decoder is TV-owned libNDL_directmedia.so.1. Full LGPL text: packaging/licenses/SS4S-LGPL-3.0.txt.
- Chiaki-lg (TacticalBill and contributors), GPL-3.0: media feed flags and transparent accelerated SDL/EGL composition used as reference; no Chiaki Remote Play core is linked.
- PlxNative: Rust staticlib/C bootstrap/ARM soft-float packaging pattern reference only; no code copied.
- PS5Upload / Chiaki / chiaki-ng: the client extracts and links ddp.rs, log.rs, rp_login_pin.rs, rp_regist.rs, rp_regist_keys.rs, rp_session.rs and rp_stream/ from commit 1d73219dd4fb95763a8c14a6b9d90cec1918bbca. The AGPL-3.0-only stream headers and all embedded protocol tests/FEC vectors are retained. See crates/psremote/UPSTREAM.md and webos.patch for the narrow extraction changes. The standalone manual-PIN API is used; payload-management/account-modification APIs, the desktop HTTP/WebSocket engine, and the frontend are absent. Licenses: packaging/licenses/AGPL-3.0.txt, GPL-3.0.txt and playactor-ISC.txt. M0 does not link the protocol.
- Aurora USB feedback: platform/client/vendor/dualsense_usb.c/.h copy the pinned USB-only implementation. A recorded strength.patch adds the output-report intensity byte using PS5Upload pad_dualsense.rs semantics (valid flag 0x40, common offset 36). Its original 63-byte report construction, device detection and trigger reset are reused. The app guards the upstream fallback to one identified USB DualSense; advanced Bluetooth writes are not enabled. Limelight.h is used only for constants, from Aurora’s pinned moonlight-common-c gitlink (no Moonlight network library is linked).
- PS5Upload pad_haptics.rs: the streaming linear upsampler and channels-3/4 routing algorithm are adapted in crates/app/src/haptics.rs for SDL queued audio. The entire desktop CPAL command layer is excluded. New native app logic is AGPL-3.0-only.
- SDL 2.32.10 and SDL2_test bitmap font, zlib license: SDK-supplied static text helper and headers only (SDK shared SDL is dummy-only and is not shipped). SDK archive SHA-256 in tools.lock.json pins the exact inputs. License: packaging/licenses/SDL.txt. SDL's API exposes controller detection/output; neither guarantees TV driver capability.
- SDL3/webOS 3.4.16-webos.5, zlib license: release archive checksum-pinned in tools.lock.json, license packaging/licenses/SDL3.txt; source commit f599b850f9b1347cebdbb9a806999ddd170ab661, https://github.com/webosbrew/SDL-webOS/tree/release-3.4.16-webos.5; included in the source review archive. SDL2 compatibility release 2.32.74 is pinned in upstream.lock.json, license packaging/licenses/SDL2-compat.txt. Two Aurora patches (webOS scancodes and private SONAME) are applied to a build copy; Aurora’s sdl2_ndl_shim.c is compiled unchanged. The app links libSDL2-webos.so.0; NDL resolves libSDL2-2.0.so.0 to the shim, which forwards exported-window operations to SDL3.
- GCC libgcc_s and libatomic runtime libraries from the pinned SDK: GPL-3.0 with GCC Runtime Library Exception 3.1. See packaging/licenses/GCC-Runtime-Exception.txt and LICENSE.
- SDL_GameControllerDB, zlib license: revision 742bfc6942b132fba040551575f926ff239d9201; Linux mappings transformed to platform:webOS using Aurora's documented generator pattern. License: packaging/licenses/ControllerDB.txt.
- Opus 1.5.2, BSD-style license: statically linked into upstream NDL module because that backend shares audio/video code, though M0 never opens audio. Archive pinned in tools.lock.json. License: packaging/licenses/Opus.txt.
- Rust 1.85.1 standard library: MIT OR Apache-2.0; toolchain supplied by rustup. Relevant license texts bundled under packaging/licenses.
